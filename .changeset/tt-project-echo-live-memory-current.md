`tt-project`: the retired-rule echo scan (`ttp echoes`, the digest's Retired-rule echoes section) treats a phrase of a retired memory entry (superseded, withdrawn or compacted) as current when any live memory entry still holds it whole: such a match is advisory, never a fix order, wherever it is quoted. A phrase only the retired entry holds, or one a live entry holds only inside a longer name, keeps its class; a user Correction or charter replacement keeps its fix orders.
