`tt-project`: a schedule's run is found by its name among the task's labels, not by the exact label list, so a daily review that gained a later label (an urgent stamp) counts as its period's run and no false "self-review: overdue" follows. The host line puts a planned reboot on the project that recorded it, else on its planner ("planned: by the device broker"), never on the project reading it.
