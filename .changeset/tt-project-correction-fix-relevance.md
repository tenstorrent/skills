Corrections: a turn's harness or `upstream:` task is a correction's class fix only when it is about that
correction (cites `correction|msg|message #<id>`, names a class anchor or shares its subject words), so a
turn settling several corrections credits each task only to the ones it matches. The recurring-mistake
Course check line counts a later correction only when its message came after the prior fix task closed
(or, while it is open, after it was created), and skips one a harness or `upstream:` task added since
already cites.
