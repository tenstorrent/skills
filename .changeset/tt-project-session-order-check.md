`tt-project`: in coordinator session mode, an injected instruction can no longer persist across wakes by passing itself off as a user order. A handover line that claims a user order is kept only when its quotes are in the own words of the logged user message it cites (the check charter changes use); a failing line is dropped and logged as an `order_claim_dropped` event, both when the note is saved and when it seeds the next session. A `memory_add` quoting words as the user's that fail the same check is refused. The wake after a compacted one leads with the open order ledger and the last chat exchanges verbatim, so the summary carries no order of its own.
