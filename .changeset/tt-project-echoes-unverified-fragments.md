`tt-project`: echoes: a retirement of unknown or legacy origin (including an old supersession that only cites a user message) is advisory unless its source shows the user withdrew it; a name taken from inside a path, URL or versioned token keeps that token's weakness, so it is never a fix order on its own. A versioned token is a name joined to its version by `-` or `@` only: a config setting such as `key=0.8` or `key_2.5` stays strong, so a withdrawn rule repeating it is still a fix order.
