`tt-project`:

- The retired-rule echo notice no longer orders a fix for the name, heading or wording of a current Restrictions item that carries its source (a user cite, origin: Brief or origin: harness gate) when the retirement is a memory entry superseded or withdrawn. Such matches, in the charter, task specs, harness files or memory facts restating the item, are counted as advisory. A user Correction's or a charter replacement's matches, and the retired entry's own wording, are still fix orders.
