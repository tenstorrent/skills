`tt-project`: the outward leak scan closes five gaps. The pre-push scan passes `--root` (a root commit is scanned even with `log.showRoot=false`) and ignores replace refs, as `pack-objects` does. A ref whose new object is a blob or tree (or a tag on one) is refused, since the scan reads commits only. In a run, git aliases are resolved for non-builtin subcommands (chained, `-c alias.*`, case-insensitive), so an alias for push goes through the push guard; `git send-pack`, `git http-push` and shell aliases that push are refused. `gh release upload` and `gh release create` scan the files they send, to their end, with the secret, token-shape and forbidden-pattern classes. Refusals by gh, `ttp note --to`, `ttp notify` and git push are recorded and counted by route in `ttp audit`.
