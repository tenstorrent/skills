`tt-project`: a commit that adds a git conflict marker line is never pushed, an intermediate one a later commit removes included. A review's approval whose head carries such a commit over the target is refused (a light conflict fix then runs again at standard), and the push batch sends such an entry back as a non-textual conflict before carrying it. Only column-0 markers count; fixture directories and `=` heading underlines in docs are skipped. The conflict-fix prompt says no commit may keep a marker.
