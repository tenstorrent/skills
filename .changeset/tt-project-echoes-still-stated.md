`tt-project`: `ttp echoes` no longer orders a fix for a retired memory entry's phrase that a current user-cited memory entry written since, or a cited Restrictions item, still states: the match is advisory and its `why` names that entry or item (`still stated by memory [name]`, `still stated by Restrictions item N (...)`). A task whose subject is the echo detector itself, quoting matches to discuss them, is advisory too. A phrase only retired entries or leftover copies hold stays a fix order.
