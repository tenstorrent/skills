ETAs that wait on another project quote its resume time. `peerhold` reads another project on this machine read-only, without a model call: whether its pause or its core provider's spend gate holds it, why, and when it resumes. `ttp note --to` prints that line and puts it in the note's facts suffix. The digest's promise line names each held project that the promise's owner tasks sent notes to. Those projects are found from the inbox's recorded sender task and target, not from the note's wording. The line flags a due that falls before the resume time, unless the promise quotes that time. The coordinator prompt has one line for this. A project on another machine counts as unknown, never as free: the spend sync carries only dollars.
