The GLM guard now treats a command substitution in an unquoted heredoc body (`` ` `` or `$( )`) as a hidden command: it cannot be read, and a reset or power cycle named in it needs the Opus check, while the same text under a quoted delimiter stays plain text. An awk program's `/regex/` and string literals are no longer read as output redirects (a real `print > "/path"` outside the worktree is still refused), and the Opus device plan prompt now says a plain file edit in the run's own worktree is listed as an `edit <file>` command.
