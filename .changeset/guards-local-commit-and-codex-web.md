`tt-project`: a project.json, charter or memory change that a harness task commits while a full-tools coordinator's shell call runs is no longer put back by the coordinator's protected-file guard (the guard keeps a change whose content the harness checkout's new HEAD holds). Codex's web search runs on the model's server, where no hook sees it, so a project whose `guards.local` guards define `tool_refusal` now runs Codex with web search off (`web_search="disabled"`), and the provider matrix says so.
