`tt-project`: a Restrictions charter_update whose `text` cites a user message that `source` does not name is repaired instead of refused. A cite of a logged user message (the user's own words, or the owner's agent's words with agent mode on) stays and the source's cite is added beside it; any other cite (an unknown id, a relayer's context alone, a note, a coordinator line) is swapped for the source's cite, now also for the owner's agent's relayer source, which was refused before. The charter history names the repair. A Brief or gate source still refuses a cite no user message backs, and a loosening still rests only on the source's checked words.
