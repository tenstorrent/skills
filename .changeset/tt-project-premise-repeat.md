`tt-project`: a premise a check already proved false is not paid for again. `task_add` refuses a code task whose premise matches a premise check that answered "fails" with full cover in the last 14 days (same commits, or the same words when it names none), naming that check; `force: true` with `differs from #<check>: <how>` in the spec still queues it. A check that rejects the premise without a `premise:` key counts as "fails". The push queue's "left out as resolved" check no longer names a commit whose lines landed verbatim or inside a longer line, and tells the coordinator about a left-out commit once, not once per batch.
