`tt-project`: the daemon reads a hand-off's `follow_ups` or `follow-ups` list as `followups`, merged with no duplicates. The progress check raises no probe stall for a wait no model turn can end while the probe says a plain not yet: a holds folder, a rollout flag, or a PR's state. It also raises none for a probe naming a machine with an open known outage, and restarts that probe's clock once the outage ends. A probe's last output line keeps its tail, so a progress counter at the end of a long line still counts. A `conclusion:` line alone no longer keeps a code task off the code route's GLM arm, but a task a chat reads still stays on Claude. The core-route reason drops a branch no run could reach.
