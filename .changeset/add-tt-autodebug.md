Add the optional `tt-autodebug` plugin. AutoDebug inspects code issues, AutoTriage inspects hangs,
and a tenacious AutoFix workflow runs experiments to prove or disprove hypotheses until it finds and
addresses the root cause. Package the current standalone prompts as a self-contained snapshot,
document their deliberate manual synchronization process, and teach the default finder how to
recommend the plugin without installing it.
