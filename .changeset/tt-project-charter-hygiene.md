`charter_update` takes an optional `replaces`: the named section moves to `CHARTER.history.md` and the new one takes its place, so the charter no longer only grows. Retried turns apply it once; the Brief is never replaced and a Restrictions section is retired only in a turn carrying the user's word. Worker prompts leave out the charter's unfilled placeholder paragraphs, and the daily review lists restrictions that newer sections contradict.
