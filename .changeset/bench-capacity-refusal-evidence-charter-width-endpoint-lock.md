Bench: a cell whose calls were over 20% capacity refusals (`bench.server.capacity_refusal_max`, default 0.2) is "not run (server)": not scored, not flagged, also when old rows are read again. A cell is flagged only when the run saw the original change or later history in a command's output or a diff matching it; a probe that found nothing is listed as "probed, nothing found" with no fail, and a sha seen only in a failed lookup's error is no leak (user msg #3538). Charter gate: a scoped exception narrows the ban itself, not an older exception that quotes it, and is compared only against what other items ban, so an item allowing work on a host or an older exception there no longer blocks it; a real ban on that action still does. Terminal-Bench reference runner: it takes the shared endpoint lock per trial and frees it during a stay-off wait, re-taking it in line before the next trial.
