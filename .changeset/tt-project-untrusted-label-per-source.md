`tt-project`: the `untrusted_input` label is set per source, model-free: on the daemon's PR-findings fix and a shared check failure's fix, on a coordinator `task_add` with `untrusted_input: true` or a peer note's `[note <fp>]` tag, and on the task of a run that read web, connector or downloaded text (the hook marks the run, the guards apply to the rest of it, and the daemon labels the task when the run ends). Continuations, review fixes and reopened copies inherit it. A labelled task never routes to the chat provider, and its run note records it.
