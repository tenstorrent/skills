The waste ledger counts a run past the per-task limit as avoidable only when it brought no new result, by the run stop's own progress test (a commit, or a done or waiting hand-off that is not its previous run's again); useful continuations are listed apart with their run, rank and the limit. The daily fix task names its flagged runs and is not queued again while one of the last 7 days already covers them.
