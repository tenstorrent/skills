The waste ledger counts a run past the per-task limit as avoidable only when it brought no new result (a done or waiting hand-off that is not its previous run's again, or a commit inside it, by the run stop's own commit test; runs that never reached the model take no rank and are no previous run); useful continuations are listed apart with their run, rank and the limit. The daily fix task names its flagged runs and is not queued again while a fix task of the last 7 days that did not fail already covers them.
