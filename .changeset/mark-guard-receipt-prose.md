The untrusted-input guard tells receipt prose apart from a real access. A python, perl, ruby, node or other script interpreter whose program or arguments name the run's untrusted-input record only inside a quoted sentence (a receipt or packet note such as 'the protected untrusted-input history was not read or changed') is no longer refused, so a Codex or Cursor run that wrote one is not stopped after the call finished. Such a sentence holds no path, option, command or shell punctuation and has no command, `.` or option before the name. A shell, eval, xargs, a pipe, a substitution or a sourced file in the same command, and any script that opens, removes or runs a command on the record, is still refused, and a finished change to it still stops the run with its saved files kept.
