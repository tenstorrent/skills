When a Restrictions item is removed, retired, or loosened by a few words, the check for project tools that may still enforce it now matches only the item's distinctive words, its quoted phrases and its user-message cite. Words found on more than about 5% of the scanned tool lines no longer count. Before, a long item's common words matched almost every tool line, so dozens of unrelated files were flagged. Each flagged file is now listed with the terms it matched.
