`tt-project`: with `coordinator.agent_orders_as_user` on, a Restrictions change the owner's agent orders (`source` origin relayer) is no longer refused as a held step for words like "postpone" or "tokens per second"; a refusal for a safety note in the new text ("no other tenant") names the resend without it (the note goes to memory or the machine change ledger), and a failed quote check names the relayer-origin resend instead of implying an ask. A new ask gate refuses a permission ask for what a logged message may already have ordered (a restriction ask citing it or repeating its words, an irreversible permission ask citing its id) and tells the coordinator to send the change or act, or to resend with `not_covered` if that message did not order it or forbade it; asks about harm to people, speaking as the owner, money or credentials still go to the owner. Agent mode off: unchanged.
