`tt-project`: a GLM guard refusal that is not harmful (reading the database by hand, `ttp upstream`, a scratch file outside the worktree) now returns the reason plus the allowed way, and the run carries on. A harmful attempt (device, machine or service acts, publishing or speaking, credentials, another project's records, deletes outside the worktree) or the third refusal in one run hands the task back to Opus as before. `route.glm_refusals` sets the count (`hand_back_after`, default 3) and an off switch (`redirect: false`). GLM prompts open with a short deny list built from the same rule table, each line with its allowed way. Refusals are logged per run in `glm_refusals.jsonl`; `guard_redirects` counts redirects apart from `guard_bounces`.
