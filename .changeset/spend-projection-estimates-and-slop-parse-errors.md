The account-wide spend projection takes its rate from measured spend: other machines' estimate of their other Claude Code sessions counts only at its average over the period, so a one-off jump in that estimate (its logs read at last) no longer raises a false 'reaches the cap' warning. `ttp slop` reports a Python file it cannot parse (syntax error, unsupported input, too deep to read) with null counters and the error, listed under `parse_errors` and the subsystem's `unparsed`, instead of counting it as clean zeros.

A credential-change observation for changes made outside a run honours the coordinator's observation mutes, and an open machine-ledger entry whose undo is `none: deliberate` covers later rewrites of the path it names, so a deliberate key rotation is not told again; a run's own credential writes are never muted.
