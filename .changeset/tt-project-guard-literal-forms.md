Guard: a fully literal, read-only `curl` of the GitHub API (GET or HEAD, no body, form, upload, config file,
header file or method override, no GraphQL URL) is no longer taken for a PR or ref write because of its
`-D` dump-header option; a write form that runs across two commands still counts. A GLM run's refusal for a
program name or operand read from an expansion now names the literal form to resend. More must-refuse tests
for hidden GitHub writes, `$TMPDIR` defaults and recursive deletes of the home folder.
