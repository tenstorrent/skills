`tt-project`:

- push notices name the exact branch and short sha, and say 'not yet on <target>' when delivery.push_branch or base_ref names another branch the work has not reached (with how many commits it is behind); the reach check is bounded (60 s fetch, no prompt, no stdin) and guarded, and a batch checks reach before it writes its outcome
- a push branch no push can reach (main/master, or a code repo without the remote) is flagged by the config check and ttp doctor, and its reviews are review only with no push step; test gives the recorded-pass precheck repo a remote, as a remote-less repo is now review only
