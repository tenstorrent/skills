A finished task's hand-off or shipped notice posts at once only when it delivers an obligation the task owes in that chat, or reports a failure or block the user must act on; a routine one is held and folded into the chat's next status post as one line per task. The hourly status table posts only when an order closed or went overdue, a blocker or outage appeared or cleared, or the spend gate changed level, never sooner than the chat's status gap; counts, times, versions, a landed batch or a deploy alone post nothing. A guard test fails when any daemon path posting an info or reply message to a chat skips the chat's pace.
