`tt-project`: a ready urgent task held only by a spend limit that time or the user clears (the runaway guard, a dollar cap, a plan window at its line, a run that does not fit the caps) no longer raises an urgent-wait observation, which woke the coordinator for a self-started turn that added to the guard holding it. It is listed in the next turn's digest instead, one line per task with when the hold is expected to clear. Pauses, locks and other holds still wake the coordinator.
