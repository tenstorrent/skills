`tt-project`: `ttp push --retire` counts the project's own single-push receipt (status `pushed`, exit 0, own, its target naming the branch) as its push record; failed, unowned and other-target receipts still refuse. The bridge watcher keeps a port's owed restart marked when the restart is refused, so a later pass still restarts it. The GLM arm's database rule reads a python heredoc's code, not its comments or the multi-line literals it writes into a file; a one-line literal naming the database still refuses.
