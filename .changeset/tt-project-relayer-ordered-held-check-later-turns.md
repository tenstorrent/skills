In agent mode the coordinator's charter guard runs the held-class check on every Restrictions change cited as relayer-ordered, in later turns with no messages too. Before, a scoped exception (`excepts`) or a `both_hold` item resting only on the owner's agent's words could, in a later turn, store a held loosening such as posting as the owner; it is now refused by class, as in the agent's own turn.
