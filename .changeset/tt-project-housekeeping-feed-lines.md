Housekeeping is a feed line, not a user alert: a memory retirement posts as an info line (the digest still lists it), and a long daemon stop that cut no run short and missed no schedule run is a low feed line instead of a chat message. A reboot that cut work short, a daemon that fails to start and a deploy still behind after its takeover time still alert. A guard test lists every runtime `kind='alert'` post site with its charter notify class (decisions, reviews, merges, funds, outages, user-only blocker); a new unlisted site fails it.
