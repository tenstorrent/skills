`tt-project`: fewer false GLM hand-backs, and a clearer rollback reason. A key named only in the text an interpreter reads from a quoted heredoc (a script's test string) is a redirect the run can fix; a body that opens the path still hands back. The secret check now comes before the scratch redirect, so copying a key to a scratch folder still hands back. Setting `TMPDIR` to the run's own scratch folder, an arithmetic `$(( ))` around a command substitution and a `sed` script in single quotes no longer read as an identity edit, a hidden expansion or a write outside the worktree; the `e` flag of `sed` and an expansion after `;` or `|` still hand back. A GLM run that started on the `glm_work` route is no longer policy-bounced because a rollback took the route while it ran. A rollout rollback reason now leads with the failing metric, GLM's value, the Claude baseline's value and the margin, then the passing ones labelled as within the margins.
