`tt-project`:

- a waiting hand-off's next_step (a mechanical step left) wakes at light and that run finishes it; an escalated light wake runs at the task's tier even if its hand-off keeps next_step
- only external waits raise coordinator effort or count as stuck; self-waits reported apart; repeated waits raise on a changed wait reason, a 24 h stint or a count backstop, never on light-wake escalations
- optional review.light_paths allow-list for light reviews
- review lists every blocking finding in one pass; fix tasks test each bug class
- harness tasks deliver by a local commit; ttp push in a remote-less harness says so and exits 0
- ttp push refuses a worktree on another task's branch and defaults to the task's own published branch without a push branch
