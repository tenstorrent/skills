The gates that pick a task's base branch and a project's machines read only structured settings (`delivery.base_ref`, `delivery.push_branch`, `worktree.shared_branches`, `machines.allowed`, `resources`, `shared_resources`), never the charter's wording. The daemon's first start moves the machines and branches the charter's prose named into those settings once, model-free and logged; nothing moves that the old reader did not use, and `delivery.push_branch` is never written.
