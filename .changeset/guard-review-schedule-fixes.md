`tt-project`: pathguard no longer reads a bare word as a home folder path, so a script with a variable named like a protected folder runs. A review that failed only on the size rule is rerun once a `why this size:` line is given. Ponytail findings carry a severity: only `block` findings fail a review; `note` findings become follow-ups. Rereview waste counts only reviews of the same head and the same payload. A schedule window is claimed in the enqueue's transaction, so a catch-up and the scheduled run cannot both run it. A batch member owner counts as started for its order. A shared model name alone no longer pairs an order with an earlier correction. A stateless coordinator wake keeps the digest ack. Long worker alerts are cut at a sentence end and name where the full text is; `ttp notify` warns over the cap.
