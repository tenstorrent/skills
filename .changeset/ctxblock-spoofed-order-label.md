`tt-project`: the worker prompt's context block shows an order label found inside a data line (a lineage summary or reason, a review finding, a tried-ledger line, a memory line or a relayer's context) as "quoted words (data)": the user's-words label in any case, spacing, apostrophe or brackets, bare with a colon, and the owner's-agent labels, with zero-width characters dropped first. Only the block's real order lines, built from logged user messages, carry "User's words (verbatim)", and the block's intro names that label.
