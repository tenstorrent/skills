`tt-project`: `ttp ack-wait probe --terminal` classifies only the author's words, whatever whitespace precedes the appended facts block. A forked worker's prompt ends with the hand-off rule; a run that ends under the coordinator's role is retried once with that rule and its reason, and a second such run is not retried again. The outside-write record names the run-end scan that saw a write no guard refused. The order audit no longer counts an order settled without a task (a reply, a memory or charter change) as unstarted. In a quiet project whose wakes mostly resume cold, the default compaction point stays under the context whose cold rewrite costs `waste.wake_usd`, so the same session compacts in place sooner. `ttp config get --why` shows numbers and flags under secret-looking keys (such as `compact_tokens`) instead of redacting them.
