Budget alerts go to the user only for what only the user can clear (a dollar cap they set, or funds:
the provider's spend limit), and only once that red still holds new work two minutes after it began,
so a one-tick flap is no alert. A plan window's line, the runaway guard and a provider that stops
reporting plan windows (and moves to the dollar caps) are the gate's status line, never a red alert,
and the alert names only the reasons that hold the work. An alert is withdrawn as soon as no cap or
funds reason holds work, even while the gate stays red for a reason that lifts by itself.
