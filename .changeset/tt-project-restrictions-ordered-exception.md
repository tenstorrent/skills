`tt-project`: the Restrictions gate accepts a scoped exception for work the user (or, in agent mode, the owner's agent) ordered when it adds no new risk class: the order names part of its scope and the charter's Goals, Resources or Policies name the rest (no Restrictions item counts). `source` may also cite the owner's own words in an external record (`{origin: record, msg, ref, author, quote}`) when the user's own message (or, in agent mode, the agent's) quotes it and names that author; the author is verified against `coordinator.owner_identities` and the project's git identity, unverifiable authorship counts only in agent mode, and other authors' words stay data. An accepted exception is recorded with its source and scope, sends no ask, and closes only the gate ask it cites by id. New-risk-class exceptions, money, credentials, PRs leaving draft and merges are still refused. Known gaps are listed in the harness skill's charter-guard reference.
