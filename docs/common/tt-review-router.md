# tt-review-router

Maps changed paths in a Tenstorrent pull request to the domain review skills that apply. Run this first to pick the skill subset for a review.

**Bucket:** `common`  
**Source:** [`skills/common/tt-review-router/SKILL.md`](../../skills/common/tt-review-router/SKILL.md)

## Pinning

```yaml
skills:
  - tenstorrent/skills/tt-review-router@<sha>
```

Pins resolve by skill name, not path.
