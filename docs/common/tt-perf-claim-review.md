# tt-perf-claim-review

Reviews performance claims rather than performance changes — whether the measurement supports the assertion. Covers device duration versus wall time, bound classification, first-run program-cache caveats, absolute versus percentage comparisons, and warmed traced harness parity. Use when a PR body, comment, or test asserts a speedup, a regression, or a throughput number.
