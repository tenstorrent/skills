# Code Comments

Comments state present-tense intent: why the code is this way.

- Default to no comment.
- Add one only when its absence confuses a reader.
- Explain *why*. The code shows what.
- Cite invariants, hidden constraints, surprising-but-correct choices.
- NEVER narrate history: earlier versions, tried ideas, removals.
- NEVER cite the conversation, ticket, PR, or person.
